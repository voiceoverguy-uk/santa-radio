name: Workshop choice controls
description: Owner-required selection controls for Santa’s Message Workshop.
---

All workshop choice categories should use horizontal scrollers, except names, which must use live search.

**Why:** The owner said: “all of them should use a scroller just NOT the names as too many. So they need to be live search.”

**How to apply:** Apply horizontal scrollers consistently to age, activity, achievement, festive treat and magical place. Keep name selection searchable rather than a scroller.
