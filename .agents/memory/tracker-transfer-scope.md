---
name: Santa Tracker transfer constraints
description: Owner intent behind source preservation, separate host identities and optional reminders.
---
Preserve the supplied tracker's content, calculations and functionality rather than recreating it. Adapt it to Santa Radio's existing framework rather than migrating the host application to the transfer project's framework.

**Why:** The owner requested a focused integration of the actual source and assets, retaining its calculations, seasonal content and working features.

**How to apply:** Keep future adaptations narrow; a framework migration or functional tracker redesign needs a new explicit request.

Use the owner's supplied map image as a blurred decorative background behind the homepage Tracker section.

**Why:** The owner explicitly asked to blur that image into the section background.

**How to apply:** Keep the live foreground map, copy and button sharp and functional; do not extend the backdrop to the full Tracker page.

For an app-project handover, export the current shareable website source rather
than reusing the original imported tracker archive. Distinguish a reachable
published reference from proof that production matches the exported source.

**Why:** The owner requested the latest website appearance and enlarged homepage
map for a separate iOS/Apple TV project; an earlier transfer archive is not an
up-to-date source snapshot.

**How to apply:** Preserve source and assets, sanitise operational data and
credentials, and document actual live verification separately. Native adaptation
and device compatibility remain the receiving project's work.

For iPhone-only tracker handovers, isolate the current tracker page and its
required dependencies rather than exporting the whole website or reusing the
earlier iOS/Apple TV archive.

**Why:** The owner explicitly requested the current appearance and seasonal
behaviour without unrelated website services, and limited this handover to iPhone.

**How to apply:** Keep adaptations export-only; distinguish bundled-web guidance
from a native port and browser/file-origin checks from actual WKWebView testing.

For fresh mobile handovers, treat the current tracker source and its current
tests as authoritative, not the tests or documentation embedded in an older
handover generator.

**Why:** Older handover templates can retain obsolete itinerary and seasonal
expectations even when they copy newer runtime files.

**How to apply:** Reconcile imported dependencies, assets and checks against the
current source. In an export-only request, document existing runtime discrepancies
rather than silently correcting website behavior outside the requested scope.

Tracker presentation should match the actual established Santa Radio homepage and Christmas Music styling, not retain the imported blue theme. Use the site's heading/body typography, green surfaces, readable gold/cream accents, red actions and matching cards, borders and spacing; preserve intentional handwritten postcards and festive effects.

**Why:** After the transfer, the owner explicitly requested brand-matching styling while leaving content, calculations, preview behaviour, radio and cross-promotion intact.

**How to apply:** Scope visual refinements to tracker presentation and its associated homepage feature. Do not change shared site styles to accommodate imported tracker classes.

Santa Radio is the tracker host identity. SantaGuy remains relevant cross-promotion and the voiceover destination; adding the tracker here does not imply removing, replacing or redirecting SantaGuy's existing tracker.

**Why:** The owner explicitly wanted the Santa Radio integration without changes on SantaGuy.

**How to apply:** Distinguish host branding from creator credit and external links. Never bulk-replace SantaGuy references or infer permission to alter its live website.

The “Santa’s voice by Guy Harris” credit links to voiceoverguy.co.uk. The separate SantaGuy availability CTA remains unchanged.

**Why:** The owner explicitly corrected the creator-credit destination.

**How to apply:** Keep the creator credit separate from the SantaGuy voiceover-service cross-promotion.

Tracker reminders are conditional, not an assumed signup requirement: only show them with a compatible provider and complete consent/unsubscribe flow.

**Why:** The owner explicitly asked to omit both the UI and backend when these are not already compatible.

**How to apply:** Report missing setup rather than adding a non-functional form or enrolling existing enquiry contacts.
