The workshop's final-stage MP3 filename preview uses `santa-message-for-(NAME).mp3`,
substituting the chosen written name without literal parentheses.

**Why:** The owner specifically requested removing “recorded” from the final-stage filename preview.

**How to apply:** Keep custom written spelling reflected in that preview, without changing recording identity. This request concerned the workshop's last stage, not renaming hosted sources, saved URLs or changing the existing free maker's separate download convention below.

## Existing free-message downloads

Use `santa-recorded-message-for-(NAME).mp3` for Santa recorded-message downloads,
substituting the selected display name without literal parentheses.

**Why:** The owner asked to make the filename uniform using this exact pattern.

**How to apply:** Keep downloads, shared audio files and delivered examples
consistent. This is not permission to rename or move recordings on the external
host, or to change existing saved-greeting URLs.
