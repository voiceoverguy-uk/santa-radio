---
name: Music catalogue source scope
description: Inclusion policy for the supplied song database.
---
Include all songs in the supplied database, even if some had previously been removed from the website. The user will choose removals later.

**Why:** The user explicitly requested the full database rather than restricting imports to current site entries.

**How to apply:** Preserve historical song URLs while enriching or correcting catalogue data. Do not treat absence from the old site as a reason to exclude a database record.
