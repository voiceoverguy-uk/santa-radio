---
name: Santa recipient preview priority
description: Owner requires selected/generated child names instead of random examples after personalisation.
---

If someone uses the free message or checks a name in the homepage name checker,
the message maker should only show the name they just generated or checked.
Random messages are only for visitors who have not generated a free message or
selected a name at the top of the homepage.

**Why:** The user explicitly requested this after showing the Studio gift
previews and a random example-audio button beneath the free-greeting card.

**How to apply:** Treat this as a restriction on both gift recipient rotation and
Santa sample playback, not on unrelated radio music. Keep the existing child-name
privacy and refresh-reset requirements; do not infer permission to persist names.
