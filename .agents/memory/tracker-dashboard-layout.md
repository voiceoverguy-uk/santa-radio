---
name: Tracker dashboard layout
description: Owner's desktop requirement for journey statistics alongside the map.
---
On desktop, show the Estimated Dashboard on the left and right of the map, with four regular cards on each side. Keep smaller-screen statistics below the map in a readable grid.

**Why:** The owner wants visitors to see the changing journey figures while watching the map, without scrolling down to a separate dashboard.

**How to apply:** Preserve one shared set of live statistics, seasonal values and the extra UK arrival detail when rearranging the tracker. Do not return the desktop dashboard to a separate lower section.
