name: Studio page starting position
description: Owner-approved mobile framing for every Studio page.

On mobile, every Studio page should open with the creation panel immediately below the Santa Radio navigation, with the panel kicker, step indicator and current question visible—not the large introductory Studio title.

**Why:** After requesting this for page two, the owner clarified “All the message maker pages should load to this position.”

**How to apply:** Preserve this framing on initial entry, forward and backward navigation, review and editing any answer. Keep desktop scroll positioning unchanged.

Each question is the main card heading, replacing both “Your Christmas creation” and “A few lovely details”. Do not repeat it in a separate numbered row below the progress bar. Count the seven selection questions as “Step X of 7”; the owner separately requested “Step 8 of 8” for review.

**Why:** The owner explicitly requested this to reduce words and clutter, then explicitly chose the review badge as “Step 8 of 8”. Do not unify these different totals without asking.

**How to apply:** Keep the progress bar beneath the question and retain the valid-choice Continue shortcut on all screen sizes. Move keyboard focus to the current question heading on navigation.

On mobile, tablet and desktop, use the top-right step badge position as a Continue shortcut once the current choice is valid, retaining the lower navigation and normal step badge when no choice is valid. The review page must not turn this shortcut into message generation.

**Why:** The owner requested that highlighting a selection make the “step 7 of 8” badge a Continue button so users do not need to scroll down, then explicitly extended this behaviour to web/desktop.

**How to apply:** Use the same validation and navigation as the lower Continue control, including county/state selections and return-to-review editing, at every viewport width.

The review's bottom-left control is “Start Again”, returning to the first step rather than the previous destination step. Earlier steps retain “Back”.

**Why:** The owner requested this because individual sections already have their own edit controls. Restarting navigation must not silently discard recordings or reset server-enforced allowances.

**How to apply:** Preserve existing selections and completed downloads while revisiting the flow. Keep deliberate voucher-test generation renewal separate from this navigation action.
