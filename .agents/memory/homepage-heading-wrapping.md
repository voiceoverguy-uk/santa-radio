---
name: Homepage heading wrapping
description: Responsive heading line breaks and text enlargement on the Santa Radio homepage.
---

Use explicit line breaks for approved editorial line layout, but keep subsequent text free to wrap naturally when browser text is enlarged. If a standard phone width needs more room, expand the heading's layout box symmetrically instead of changing the established type or forcing an unbreakable line.

**Why:** A forced no-wrap Dash title clipped or overflowed when text was enlarged. Keeping the typography and widening the normal-size heading box preserved the intended two-line phone layout while allowing 200% text to reflow.

**How to apply:** For homepage heading changes, verify desktop, a normal phone width, narrow phones, and enlarged text. Check both the visual line arrangement and document horizontal overflow.
