# Christmas Apps scenery

The decorative scenery was derived from the owner's supplied demo using
Replit image editing: all navigation, phone, logos, text, cards and buttons were
removed, retaining the luminous gold lights, fir greenery, red presents,
baubles and wooden tabletop. The edited PNG is retained locally under
`generated-artifacts/christmas-reference-scene-master.png` (ignored review
storage); only optimised WebP derivatives ship with the page:

- `src/pages/assets/christmas-room-wide.webp`: 1440 × 900 desktop stage.
- `src/pages/assets/christmas-room-mobile.webp`: 720 × 720 mobile stage.

The image editor returned a square canvas. The desktop derivative preserves
the proportions of both decorated edges; only the quiet centre and tabletop
texture are extended horizontally to create the landscape stage.

These are decorative CSS backgrounds, so they add no duplicate accessible
content. The page supplies all product wording and links as responsive HTML.

All existing owner-supplied product images remain unchanged. Only the current
Santa Radio iOS screenshots receive a black-glass and reflective metallic
iPhone shell, with side controls and grounding shadows. The screenshots already
contain the camera cut-out, so no duplicate cut-out is painted over them.
Existing Watch, Mac,
Christmas Radio, Voicemail, Messages and Text promotional compositions already
contain their devices and retain their complete proportions without another
phone frame. Santa Dash keeps its full landscape artwork in a landscape bezel;
the separate Apple TV screenshot receives a television presentation.

The page follows the owner's supplied layout reference
`attached_assets/App_page_layout_idea_1793372403986.jpeg`, while retaining the
site's Cinzel/Inter typography and existing shared shell.
