## Christmas-date timekeeping

[IANA Time Zone Database](https://www.iana.org/time-zones) rules are read using
`Intl.DateTimeFormat`, for 25 December in the journey year. Tests independently
check local midnight at each expected arrival, including minutes. These are
**37 represented Christmas UTC offsets**, not every time zone used year-round.
Broad existing route labels use one representative city, not all offsets in
the named region.
